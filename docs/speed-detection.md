# Speed Detection

Movement and attack speed manipulation are common issues in Metin2 private servers.

M2Guard analyzes gameplay synchronization and movement consistency to identify abnormal behavior patterns.

## Validation Layer

The system validates:

- Character movement timing
- Attack interval consistency
- Client-server synchronization
- Runtime gameplay behavior

## Objectives

The goal of the protection layer is to improve:

- Fair gameplay
- PvP balance
- Server stability
- Player experience
