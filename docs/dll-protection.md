# DLL Protection

DLL injection is one of the most common manipulation methods used against online game clients.

M2Guard includes runtime validation systems designed to detect suspicious module loading activity inside the Metin2 client process.

## Detection Methods

The protection layer monitors:

- Loaded modules
- Runtime memory behavior
- Unauthorized process interaction
- Suspicious execution patterns

## Why DLL Protection Matters

External module injection may lead to:

- Gameplay manipulation
- Unfair PvP advantages
- Automation systems
- Client instability
